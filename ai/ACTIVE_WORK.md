When you finish, move your row to the bottom of the table with a `DONE` status or remove it and note completion in `CHANGELOG.md`.

## Rules

Before starting significant work, developers/AI agents should register:

- **Developer** (name/handle)
- **AI Tool** (e.g., Codebuff, Cursor, Copilot, Lovable agent)
- **Task** (one-line description)
- **Branch** (feature branch name, or `main`)
- **Status** (e.g., PLANNED / IN PROGRESS / DONE)
- **Started** (date)
- **Affected Areas** (routes/components/content/integrations/ai docs)
- **Affected Files** (concrete file paths)
- **Expected changes** (brief description — add under the table row or as a note)

### Coordination etiquette

1. **Check this table before starting** any task touching shared files (`site-shell.tsx`, `enquiry-dialog.tsx`, `content/site.ts`, `styles.css`, `routes/*`).
2. If your task overlaps an IN PROGRESS row, coordinate first — do not silently edit the same files.
3. Update your row as you go (status → DONE when finished).
4. Keep rows accurate: stale rows are worse than no row.
5. This table is the **manual precursor** to an automated coordination service.

> **Do NOT build the coordination service now.** This file will later be replaced/augmented by an automated service; until then it is maintained by hand as part of the AI engineering context system.
